# 🛰️ ORBIT

> مرکز فرماندهی شخصی شما در مدار تکنولوژی

## 🚀 دموی زنده
👉 [مشاهده دمو](https://sparkly-taiyaki-daf07d.netlify.app)

## ✨ امکانات
- فید خبری چندمنبعی (NewsAPI + RSS + Mock)
- دسته‌بندی هوشمند (۷ دسته)
- جستجوی لحظه‌ای
- یادداشت‌برداری سریع (Ctrl+K)
- نمودارهای تحلیلی (روند، میله‌ای، حلقه‌ای)
- تم تاریک/روشن
- پشتیبانی کامل RTL و فارسی
- UI سایبرپانک با Glassmorphism
- موبایل و دسکتاپ بی‌نقص

## 🛠️ تکنولوژی‌ها
- Next.js 16 (App Router + Turbopack)
- TypeScript
- Tailwind CSS v4
- Zustand

- ۷۱ فایل ماژولار
